::title::
Criterio de análisis para la actividad

::content::
Para priorizar una mejora, revise cuatro preguntas:

* ¿Qué activo de información se afecta?
* ¿Cuál es la causa del problema?
* ¿Qué evidencia demuestra la situación?
* ¿Qué acción reduce el riesgo o mejora el control?

Una mejora no es solo “hacer algo nuevo”.

Una mejora debe cerrar una brecha, reducir un riesgo o aumentar la eficacia del SGSI.

<!--
Notas del presentador:
Explique que muchas organizaciones confunden actividad con mejora. Comprar una herramienta, crear una política o hacer una capacitación no mejora automáticamente el SGSI. La mejora aparece cuando existe evidencia de cambio positivo: menos incidentes, mayor cumplimiento, controles más efectivos o reducción de exposición al riesgo.

::title::
Términos clave de la sesión

::content::
SGSI
Sistema que integra políticas, procesos, personas, tecnología y controles para proteger la información.

Riesgo
Posibilidad de que una amenaza aproveche una vulnerabilidad y afecte la información.

Control
Medida para reducir probabilidad, impacto o exposición al riesgo.

No conformidad
Incumplimiento de un requisito del sistema, la norma o la organización.

Acción correctiva
Medida orientada a eliminar la causa de una no conformidad o problema.

<!--
Notas del presentador:
Aclare que estos términos deben interpretarse de forma integrada. Un riesgo puede generar un control; un control puede fallar; una auditoría puede detectar una no conformidad; una acción correctiva busca eliminar la causa, no solamente corregir el síntoma.
-->

::title::
Errores frecuentes al interpretar la mejora continua

::left::
Errores comunes:

* Pensar que mejorar es solo crear más documentos.
* Revisar riesgos una sola vez.
* Medir sin tomar decisiones.
* Capacitar sin evaluar comprensión.
* Cerrar hallazgos sin analizar causa.
* Ignorar proveedores externos.

::right::
Buenas prácticas:

* Medir desempeño de controles.
* Actualizar riesgos cuando cambia el contexto.
* Documentar evidencias verificables.
* Involucrar a la dirección.
* Escuchar al personal.
* Aprender de incidentes.
* Priorizar por impacto y probabilidad.

            })

    return brechas


def clasificar_prioridad(nivel, brecha_maxima):
    if nivel == "Alto" or brecha_maxima >= 40:
        return "Prioridad alta"
    if nivel == "Medio" or brecha_maxima >= 20:
        return "Prioridad media"
    return "Prioridad baja"


def generar_reporte():
    print("REPORTE DE MEJORA CONTINUA DEL SGSI")
    print("Fecha de análisis:", date.today())
    print("=" * 60)

    print("\n1. PLANEAR: análisis de riesgos priorizados")
    riesgos_analizados = []

    for riesgo in riesgos:
        puntaje, nivel = calcular_nivel_riesgo(
            riesgo["probabilidad"],
            riesgo["impacto"]
        )

        accion = recomendar_accion(riesgo, nivel)

        riesgos_analizados.append({
            "id": riesgo["id"],
            "activo": riesgo["activo"],
            "puntaje": puntaje,
            "nivel": nivel,
            "accion": accion
        })

    riesgos_analizados = sorted(
        riesgos_analizados,
        key=lambda item: item["puntaje"],
        reverse=True
    )

    for riesgo in riesgos_analizados:
        print(f"\n{riesgo['id']} - {riesgo['activo']}")
        print(f"Nivel de riesgo: {riesgo['nivel']} | Puntaje: {riesgo['puntaje']}")
        print(f"Acción sugerida: {riesgo['accion']}")

    print("\n2. HACER: acciones iniciales recomendadas")
    print("- Formalizar responsables y fechas de cierre.")
    print("- Ejecutar acciones correctivas sobre riesgos altos.")
    print("- Actualizar evidencias documentadas.")
    print("- Comunicar cambios relevantes al personal involucrado.")

    print("\n3. VERIFICAR: brechas frente a las metas del SGSI")
    brechas = evaluar_metricas(metricas, metas)

    if not brechas:
        print("Todas las métricas cumplen la meta definida.")
    else:
        for brecha in brechas:
            nombre = brecha["metrica"].replace("_", " ")
            print(f"- {nombre}: actual {brecha['valor_actual']}%, meta {brecha['meta']}%, brecha {brecha['brecha']}%")

    print("\n4. ACTUAR: oportunidades de mejora")
    brecha_maxima = max([b["brecha"] for b in brechas]) if brechas else 0

    for riesgo in riesgos_analizados:
        prioridad = clasificar_prioridad(riesgo["nivel"], brecha_maxima)
        print(f"- {riesgo['id']}: {prioridad}. Ejecutar seguimiento hasta verificar eficacia.")

    print("\n5. Lecciones aprendidas de incidentes")
    for incidente in incidentes:
        print(f"\n{incidente['id']} - {incidente['descripcion']}")
        print(f"Causa probable: {incidente['causa_probable']}")
        print(f"Control relacionado: {incidente['control_relacionado']}")
        print("Mejora sugerida: documentar causa raíz, responsable, acción correctiva y evidencia de cierre.")

    print("\n6. Recomendación para revisión por la dirección")
    print("- Presentar riesgos altos y brechas de métricas.")
    print("- Solicitar recursos para formación, evaluación de proveedores y pruebas de respaldo.")
    print("- Definir responsables, fechas y evidencias para la siguiente revisión.")
    print("- Verificar eficacia de las acciones implementadas.")
